## 🚀 Featured Projects

### 🔊 [VoxShield](https://github.com/rssrivallabha/voxshield)
**AI-Powered Real-Time Voice Security Gateway**

A voice-security system designed to detect AI-generated voice cloning and impersonation attacks during live calls.

- Real-time voice analysis
- Synthetic speech detection with **RawNet2**
- Speaker verification with **ECAPA-TDNN**
- Evidence fusion and continuous risk assessment
- FastAPI + WebSockets backend
- Next.js + React + TypeScript frontend

---

### 🧪 [Omega Fuzz](https://github.com/rssrivallabha/omega-fuzz)
**Source-Level Intelligent Fuzzing Platform**

A local fuzzing platform that uses **AST analysis** to extract constraints and generate high-value boundary inputs instead of relying purely on random mutation.

- Multi-target campaign orchestration
- Intelligent constraint-based seed generation
- Crash classification and deduplication
- Real-time telemetry
- Forensic PDF reporting
- Python, JavaScript/TypeScript, C++, Go, Swift & SQL adapters
